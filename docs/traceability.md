# 요구사항 대조표

기준: AI 코어 프로젝트 2회차 요구사항 정의서(1021) 2.7장 요구사항 표와 3장 구현 명세.
명세의 항목(◆)마다 구현 위치와 확인 방법을 적는다. 확인 결과의 근거는 [verification.md](verification.md)(셀프 체크리스트)와 [test_results.md](test_results.md)(테스트 결과표)에 있다.

상태: 충족 / 부분 충족 / 미충족. 기준일 2026-10-22.
